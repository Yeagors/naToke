Логотипы платёжных систем для страницы оплаты (payments/show).

Положите сюда официальные файлы (SVG предпочтительнее), названные строго так:

  sbp.svg    — логотип «Система быстрых платежей» (СБП).
               Официальные логотипы: https://sbp.nspk.ru/ (раздел для участников/брендбук НСПК).

  tbank.svg  — логотип Т-Банка.
               Официальные логотипы и правила: https://www.tbank.ru/about/brand/

Пока файлы отсутствуют, картинки на странице оплаты просто не отображаются
(скрываются через onerror) — вёрстка не ломается.

Важно: используйте логотипы строго по правилам соответствующих платёжных систем
(размеры, отступы, фон, цвет). Это требование эквайринга.
